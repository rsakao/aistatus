# Contributing

Issues and pull requests are welcome.

1. Create a branch from `main`.
2. Keep changes focused and avoid adding dependencies unless necessary.
3. Run `swift test` and `git diff --check`.
4. Do not commit credentials, signing certificates, provisioning profiles, or
   notarization data.
5. Describe user-visible behavior and security implications in the pull request.

By contributing, you agree that your contribution is licensed under the MIT
License.
